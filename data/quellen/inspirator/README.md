# Quelle: Heimabend-Inspirator (DPBM) / gruppenstunde.de

- `inspirator-ideen.json` – 211 Ideen, aufbereitet aus den Django-Fixtures des Repos
  https://github.com/RobertBagdahn/inspi (Stand der Fixtures: März 2024) mit `scripts/convert_inspirator.py`.
  Autor*innen-E-Mails wurden entfernt, Dubletten bereinigt, IDs zu Klartext aufgelöst.
- `master-data/` – Original-Stammdaten (Themen, Stufen, Arten, Orte, Zeiten, Einheiten) als Referenz.
- Live-Seite: https://gruppenstunde.de/activity/ (hat inzwischen ~398 Ideen; die neueren sind nicht im Repo).

**Lizenz der Inhalte:** CC BY-NC 4.0 laut Impressum (https://gruppenstunde.de/general/footer/impressum/).
Das heißt: nur nicht-kommerziell, immer mit Namensnennung „Heimabend-Inspirator (DPBM)“ + Autor*in.
Der Code der Repos hat keine Lizenzdatei. Vor einer Veröffentlichung unseres Tools mit diesen Inhalten
beim DPBM anfragen: inspirator@dpbm.de (Maintainer: Robert Bagdahn).

Diese Ideen gehören im Baukasten in die Kategorie **Projekte** (ganzer Heimabend zu einem Thema),
nicht zu den einzelnen Spiel-Bausteinen.
